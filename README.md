# ☕ 30 Days of Java Challenge

I’m starting a **30 Days of Java** learning challenge to build a strong foundation in Java and core programming concepts.  
This repository documents my **daily progress**, **code implementations**, and **learning outcomes** as I grow consistently—one day at a time.

> 📌 Focus: Core Java, problem-solving, clean code, and development best practices.

---

## 🚀 Why This Challenge?

Java is a powerful, industry-relevant language used in:
- Backend development
- Enterprise applications
- Competitive programming
- Android & system-level software

This challenge is my commitment to:
- Learn Java **from fundamentals**
- Practice **daily coding**
- Build a public learning record on GitHub

---

## 🎯 Goals

- Build strong Java fundamentals  
- Understand object-oriented programming deeply  
- Improve logical thinking & debugging skills  
- Maintain consistency and discipline  
- Prepare for future backend & software roles
